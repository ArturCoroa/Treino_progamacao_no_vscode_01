## O que eu fiz hoje?
Aprendi a criar um questionário interativo em Python com `input()` e bloqueio por idade usando `if/else`.

## Como funciona
- O programa pergunta nome, idade, altura, cor, animal, hobbie e trabalho.
- Se a pessoa tiver 18 anos ou mais, ele mostra todos os dados.
- Se tiver menos de 18, aparece `acesso negado!`.
